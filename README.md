# 金坛麻将

常州金坛玩法。手机上装到桌面就能离线打，也能开房间和朋友联机。

- **单机**：三个电脑陪打，随时能停。
- **联机**：开房发链接，人不够电脑补上。牌墙只在服务器上，谁都看不到别人的牌。
- 玩法特色：不吃牌、一花起胡、字牌刻子算花、过水不能胡、独吊例外。

---

## 改代码从哪下手

源码在 `src/`，**不要直接改根目录的 `index.html`**（那是构建产物，一改就被覆盖）。

| 文件 | 装什么 | 谁在用 |
|---|---|---|
| `src/rules.js` | 牌型判定、造牌、洗牌、牌的基本属性 | **浏览器和服务端共用同一份** |
| `src/score.js` | 算番、花数、封顶、过水判定 | 浏览器 |
| `src/ai.js` | 电脑出牌：向听、进张、弃牌选择 | 浏览器 |
| `src/tiles.js` | 42 张牌面的 SVG（基本是数据） | 浏览器 |
| `src/app.js` | 界面、联机、单机回合循环、存档、设置 | 浏览器 |
| `src/模板.html` | HTML 骨架和全部 CSS | 构建时套在外面 |
| `_服务端/worker.js` | 房间、发牌、回合顺序、碰杠胡仲裁 | Cloudflare Worker |

改完跑一次：

```bash
node 构建.mjs
```

它做三件事：把五个模块拼回 `index.html`、按 `src/app.js` 里的 `VERSION` 同步
`version.json` 和 `sw.js` 的缓存名、把要部署的文件拷进 `_上传这个文件夹`。

> **版本号只写在 `src/app.js` 的 `VERSION` 一处**，另外两处是生成的，别手动改。

### 为什么规则要单独一个文件

服务端要判「这张牌能不能让他胡」，客户端要算番。以前这两处各写了一份
`canWinShape` / `allMeldForms` / `counts34`，改规则得记着改两遍——漏一遍就是
服务端弹了胡按钮、客户端算出来不成立。现在 `_服务端/worker.js` 直接
`import ... from "../src/rules.js"`，只有一份。

`_测试_规则.mjs` 里有一条专门钉这件事：同一批牌型，服务端的 `canWinShape`
和客户端的 `canWinHand` 必须给同一个答案。

## 测试

```bash
node _测试_规则.mjs
```

47 条，测规则、番种、花数、计分公式、牌墙守恒、AI 向听。**直接 import `src/` 下的
真文件**，不是抄一份出来跑，所以改坏了一定红。几秒钟出结果，不用起服务器。

联机那几个要先把服务端跑起来：

```bash
npx wrangler dev --port 8787 --local
```

然后在 `_服务端` 目录里：

| 测试 | 测什么 |
|---|---|
| `_测试_断线重连.mjs` | 房主掉线再回来，电脑会不会重新动起来 |
| `_测试_代算接手.mjs` | 房主走了朋友能不能接手；真人全退光服务器兜底 |
| `_测试_手动补花.mjs` | 摸到花停住、断线重连还欠着花、补完牌数守恒 |
| `_测试_房间稳定性.mjs` | 切到别的 app 房间还在不在、准备状态会不会丢 |
| `_测试_补花死结.mjs` | 纯逻辑，不用起服务器 |

要部署之前确认产物是新的：

```bash
node 构建.mjs --检查
```

## 部署

**网页**：把 `_上传这个文件夹` 整个拖到 Cloudflare Pages。

**联机服务**：分两段部署，细节和「为什么不能合成一个」见
[`_服务端Pages/部署步骤.md`](_服务端Pages/部署步骤.md)。一句话版本：
`workers.dev` 这个后缀在国内 DNS 和 TLS 两层都被拦，`pages.dev` 是干净的，
所以要用 Pages 当门、Worker 放房间逻辑。

## 目录

```
src/              源码（改这里）
构建.mjs          拼装 + 同步版本号 + 拷到上传目录
index.html        构建产物，别手改
_上传这个文件夹/    构建时自动同步，直接拖给 Pages
_服务端/           Worker：房间逻辑 + 联机测试
_服务端Pages/      Pages 入口，转发给上面那个 Worker
_牌面素材/         牌面 SVG 原料和装配脚本
_测试_规则.mjs     规则测试
```
