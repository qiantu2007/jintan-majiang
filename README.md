# 金坛麻将

常州金坛玩法。手机上装到桌面就能离线打，也能开房间和朋友联机。

- **单机**：三个电脑陪打，随时能停。
- **联机**：开房发链接，人不够电脑补上。牌墙只在服务器上，谁都看不到别人的牌。
- 玩法特色：不吃牌、一花起胡、字牌刻子算花、过水不能胡、独吊例外。

## 改代码从哪下手

源码在 `src/`，**不要直接改根目录的 `index.html`**（那是构建产物，一改就被覆盖）。

按「我要改什么」找文件：

| 我要改… | 打开 | 行数 |
|---|---|---|
| 怎么算胡、怎么算番、封顶 | `src/score.js` | ~190 |
| 牌型判定、造牌洗牌（**服务端也用这一份**） | `src/rules.js` | ~160 |
| 电脑打得聪明不聪明 | `src/ai.js` | ~230 |
| 牌长什么样 | `src/tiles.js` | 数据 |
| 报牌的声音、音效、震动、提示条 | `src/feedback.js` | ~360 |
| 身家、称号、战绩、存档、备份码 | `src/store.js` | ~350 |
| 首页 / 我的 / 设置页 / 关于页 | `src/pages.js` | ~550 |
| 联机：连服务器、协议、房间大厅 | `src/net.js` | ~1050 |
| 牌桌怎么画、点牌怎么响应 | `src/table.js` | ~400 |
| 单机的回合流程（摸打碰杠胡结算） | `src/flow.js` | ~750 |
| 常量、全局状态、启动、PWA | `src/app.js` | ~830 |
| 页面骨架和全部 CSS | `src/模板.html` | ~1570 |
| 联机消息的约定 | `src/protocol.js` | 说明 |
| 房间、发牌、回合顺序、碰杠胡仲裁 | `_服务端/worker.js` | ~770 |

改完跑一次：

```bash
node 构建.mjs
```

```bash
node 构建.mjs
```

它做三件事：把十一个模块拼回 `index.html`、按 `src/app.js` 里的 `VERSION` 同步
`version.json` 和 `sw.js` 的缓存名、把要部署的文件拷进 `_上传这个文件夹`。

> **版本号只写在 `src/app.js` 的 `VERSION` 一处**，另外两处是生成的，别手动改。

拼装顺序在 `构建.mjs` 里写死了，动之前先看那段注释——`rules` 必须最先、
`app` 必须最后，中间几个的相对顺序也不能乱。

### 三条「只有一份」的约定

这个项目以前吃过三次同一种亏：同一件事写在两个地方，改一处漏一处。
现在这三处都被钉住了：

| 一份的是什么 | 在哪 | 谁在看着 |
|---|---|---|
| 牌型判定 | `src/rules.js`，服务端 `import` 同一个文件 | `_测试_规则.mjs` 比对两端答案 |
| 版本号 | `src/app.js` 的 `VERSION` | `构建.mjs` 生成另外两处 |
| 联机消息类型 | `src/protocol.js` 登记 | `_测试_协议.mjs` 核对两端代码 |

第三条尤其值得留意：消息类型对不上是**无声**的——服务端照发，客户端不认识
就丢掉，牌局停在那儿，控制台一片干净，而且只有真的四个人连上打才会暴露。
现在把 `"drewn"` 写成 `"drawn"` 会当场被测试拦下。客户端收到不认识的消息
也会在控制台出声，并提示对方可能是版本太旧。

## 测试

一条命令跑完能自动跑的：

```bash
node _测试_全部.mjs
```

它会依次检查：产物是不是最新的、联机消息约定、规则算番 AI（47 条）、补花死结。
联机那四个要服务端在 8787 上跑着，没有就跳过并告诉你怎么起（不算失败）。

要连联机一起测，另开一个窗口：

```bash
cd _服务端; npx wrangler dev --port 8787 --local
```

| 测试 | 测什么 | 要服务器 |
|---|---|---|
| `_测试_规则.mjs` | 规则、番种、花数、计分、牌墙守恒、AI 向听（47 条） | 否 |
| `_测试_协议.mjs` | 两端消息类型对不对得上 | 否 |
| `_服务端/_测试_补花死结.mjs` | 补花状态没清干净会锁死出牌 | 否 |
| `_服务端/_测试_断线重连.mjs` | 房主掉线再回来，电脑会不会重新动起来 | 是 |
| `_服务端/_测试_叫牌时掉线.mjs` | 被问碰不碰的那一刻掉线，回来还问不问你 | 是 |
| `_服务端/_测试_代算接手.mjs` | 房主走了朋友能不能接手；真人全退光服务器兜底 | 是 |
| `_服务端/_测试_手动补花.mjs` | 摸到花停住、断线重连还欠着花、补完牌数守恒 | 是 |
| `_服务端/_测试_房间稳定性.mjs` | 切到别的 app 房间还在不在、准备状态会不会丢 | 是 |

`_测试_规则.mjs` **直接 import `src/` 下的真文件**，不是抄一份出来跑，
所以代码改坏了它一定红。

要部署之前确认产物是新的：

```bash
node 构建.mjs --检查
```

## 部署

**网页**：把 `_上传这个文件夹` 整个拖到 Cloudflare Pages。

**联机服务**：分两段部署，细节和「为什么不能合成一个」见
[`_服务端Pages/部署步骤.md`](_服务端Pages/部署步骤.md)。一句话版本：
`workers.dev` 这个后缀在国内 DNS 和 TLS 两层都被拦，`pages.dev` 是干净的，
所以要用 Pages 当门、Worker 放房间逻辑。
