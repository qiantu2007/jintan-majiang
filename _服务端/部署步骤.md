# 联机服务器部署步骤

只做一次，之后就一直能用。全程免费，不用买服务器、不用买域名、不用备案。

用的是 **Cloudflare Workers + Durable Objects**，免费计划就够。它自带 HTTPS 网址，
所以不用自己搞证书。

---

## 为什么牌局是绝对公平的

整副牌墙**只存在服务器上**。发牌时服务器给每个人单独发一条消息，
**里面只有他自己那 13 张牌**，没有牌墙、也没有别人的手牌。

房主的手机和其他人完全一样，看不到任何人的牌。这一点是可以自己验证的：
打开浏览器开发者工具的网络面板，看 WebSocket 收到的消息里有没有别人的牌。

一局结束时服务器才把四家的牌全部公开，四个人各自用同一份数据算分，
结果必然一致，谁也改不了。

## 一、装 Node.js

如果电脑上还没有：去 <https://nodejs.org> 下载 LTS 版本装上。

装好后打开 PowerShell 验证：

```bash
node --version
```

## 二、注册 Cloudflare

去 <https://dash.cloudflare.com/sign-up> 注册，**不用填信用卡**。

## 三、部署

在 PowerShell 里进到 `_服务端` 目录：

```bash
cd "E:\vibe coding\金坛麻将\_服务端"
```

然后登录（会弹出浏览器让你授权）：

```bash
npx wrangler login
```

授权完成后部署：

```bash
npx wrangler deploy
```

成功后会打印一行网址，形如：

```
https://jintan-mahjong.你的用户名.workers.dev
```

**把这个网址记下来。**

## 四、把网址填进游戏

打开游戏 → **设置** → 找到「联机服务器」→ 把网址粘进去 → 保存。

也可以在「和朋友一起打」页面里填。

**每个要联机的人都要填一次这个网址**（包括外婆的手机）。填一次就记住了。

---

## 怎么用

1. 一个人点「和朋友一起打」→「开一个房间」，会得到一个 5 位房间号
2. 把房间号告诉朋友，或者点「复制」把邀请链接发过去
3. 朋友点链接会直接进房；也可以自己输房间号进
4. 最多四个人，**空位自动用电脑补上**
5. 房主可以选电脑难度，也可以把人请出去
6. 所有真人都点了「准备好了」，房主的「开始游戏」才能按
7. 中途掉线会自动重连，回来还是原来的座位和手牌

## 日常维护

**不用维护。** 免费额度是每天 10 万次请求，几个人打麻将用不掉零头。

要改服务端代码的话，改完重新跑一次 `npx wrangler deploy` 就行。

---

## 万一连不上

`workers.dev` 这个域名在国内**部分网络下会被污染**，如果出现连不上：

1. 先换个网络试试（比如从 WiFi 切到手机流量），确认是不是网络问题
2. 如果确实连不上，可以给 Worker 绑一个自己的域名（Cloudflare 后台 →
   Workers → 你的 Worker → Settings → Domains & Routes → 添加自定义域名）。
   域名需要先托管在 Cloudflare 上。这不需要重写任何代码，
   绑好之后把游戏设置里的服务器地址换成新域名即可。

## 文件说明

| 文件 | 作用 |
|---|---|
| `worker.js` | 服务端全部代码。房间管理、洗牌发牌、回合顺序、碰杠胡仲裁 |
| `wrangler.toml` | 部署配置。声明了 Durable Object 绑定 |

服务端**不参与算番计分**，它只管发牌和转发。分是四个客户端各自算的，
所以服务器也无从偏袒任何人。
